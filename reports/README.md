# Reports

Reference material collected while building this project — dataset notes,
Gardiner sign list sources, useful articles/papers on hieroglyph OCR or
Egyptology, library docs worth remembering, decisions and their rationale.

Purpose: a new session (human or model) picking up this project later should
be able to read through this folder and reconstruct context without re-deriving
it from scratch — what sources were used, why certain choices were made, what
didn't work.

## Conventions
- One file per topic/source, Markdown, descriptive filename
  (e.g. `2026-09-14-kaggle-dataset-options.md`, `gardiner-sign-list-source.md`).
- Prefix decision/finding docs with the date they were written if the info is
  time-sensitive (dataset availability, library versions); no date prefix
  needed for stable reference material.
- Link out to original URLs rather than copying large amounts of external
  content verbatim.
